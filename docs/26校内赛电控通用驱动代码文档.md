## 1\. 概述



本文档给出以下模块的 C 语言驱动接口与实现：



- CAN：FDCAN 经典帧收发

- M3508：C620 电调电流控制

- M2006：C610 电调电流控制

- 蜂鸣器：TIM12 PWM 驱动

- LED：SPI6 驱动的 WS2812

- 舵机：TIM1/TIM2 四路 50 Hz PWM

- FXI6X：UART5 SBUS 遥控接收

    

目标平台为 STM32H723VGT6，软件开发环境为 STM32H7 HAL 与 C11。



代码采用以下约定：



- 调用方负责电机对象存储，驱动内部状态使用固定大小的静态变量。

- 外设底层初始化由 CubeMX 生成的 `MX_xxx_Init()` 完成。

- 驱动负责过滤器配置、外设启动、PWM 配置和协议解析。

- 标识符使用英文，注释使用中文。

- 角度单位为 rad，角速度单位为 rad/s，电流单位为 A，脉宽单位为 μs，频率单位为 Hz。

    

电机槽位与 CAN ID 的对应关系如下：



|控制帧|反馈帧|槽位|
|---|---|---|
|`0x200`|`0x201`～`0x204`|0～3|
|`0x1FF`|`0x205`～`0x208`|0～3|

## 2\. 硬件资源



|模块|外设|引脚|配置|
|---|---|---|---|
|CAN|FDCAN3|PD12 = RX，PD13 = TX|经典帧，1 Mbps，标准 ID|
|M3508|FDCAN3|同 CAN|控制 `0x200`，反馈 `0x201`～`0x204`|
|M2006|FDCAN3|同 CAN|控制 `0x1FF`，反馈 `0x205`～`0x208`|
|蜂鸣器|TIM12\_CH2|PB15|1 MHz 计数，PWM 输出|
|LED|SPI6|PA5 = SCK，PA7 = MOSI|主机，只发，8 bit，6 Mbit/s|
|舵机 0|TIM1\_CH1|PE9|50 Hz PWM|
|舵机 1|TIM1\_CH3|PE13|50 Hz PWM|
|舵机 2|TIM2\_CH1|PA0|50 Hz PWM|
|舵机 3|TIM2\_CH3|PA2|50 Hz PWM|
|舵机电源|GPIO|PC15|高电平使能|
|FXI6X|UART5|PC12 = TX，PD2 = RX|100000 baud，9 bit 字长，偶校验，1 停止位|



CubeMX 侧需要完成以下初始化：



```C
MX_FDCAN3_Init();   /* CAN 控制器，经典帧，1 Mbps */
MX_TIM1_Init();     /* 舵机 0、1 */
MX_TIM2_Init();     /* 舵机 2、3 */
MX_TIM12_Init();    /* 蜂鸣器 */
MX_SPI6_Init();     /* WS2812 */
MX_UART5_Init();    /* FXI6X SBUS */
```



配置要点：



- FDCAN3 的 RX FIFO0 和 TX FIFO 各配置 8 个元素，并使能 FDCAN3\_IT0/IT1 中断。

- TIM12 的计数时钟配置为 1 MHz，对应预分频 `240 - 1`。

- TIM1、TIM2 的计数时钟配置为 1 MHz，对应预分频 `240 - 1`。

- SPI6 配置为主机、只发、8 bit、预分频 4，对应 6 Mbit/s。

- UART5 配置为 100000 baud、9 bit 字长、偶校验、1 停止位。

- PC15 配置为推挽输出，初始电平为低。

    

> 定时器时钟按 240 MHz 计算。时钟树调整后，需要同步修改蜂鸣器和舵机驱动中的预分频值。

## 4\. CAN 驱动



### 4\.1 接口与行为



`Can_Init()` 完成以下工作：



1. 保存 FDCAN 句柄。

2. 配置过滤器 0，使全部标准帧进入 RX FIFO0。

3. 配置全局过滤器，标准帧进入 RX FIFO0，扩展帧和远程帧由硬件过滤。

4. 启动 FDCAN。

5. 使能 RX FIFO0 新消息中断。

    

`Can_Send()` 将一帧标准经典帧写入 FDCAN 发送 FIFO，发送过程由外设完成。



接收路径由应用层实现 `HAL_FDCAN_RxFifo0Callback()`：



1. 检查回调对应的 FDCAN 句柄。

2. 循环读取 RX FIFO0，直到 FIFO 为空。

3. 检查帧类型和长度。

4. 调用对应电机的 `Update()` 完成解析。

    

`HAL_FDCAN_RxFifo0Callback()` 运行在中断上下文，函数体保持短小，只执行读帧和解析。



### 4\.2 `can.h`



```C
/**
 * @file can.h
 * @brief FDCAN 经典帧收发接口。
 *
 * 硬件连接：
 *   FDCAN3_RX = PD12
 *   FDCAN3_TX = PD13
 *
 * 通信参数：
 *   经典帧，1 Mbps，标准 ID。
 *
 * 接收方式：
 *   Can_Init() 使能 RX FIFO0 新消息中断。
 *   应用层实现 HAL_FDCAN_RxFifo0Callback()，在回调中读取帧并分发。
 */

#ifndef CAN_H
#define CAN_H

#include <stdbool.h>
#include <stdint.h>

#include "fdcan.h"

#ifdef __cplusplus
extern "C" {
#endif

/**
 * @brief 初始化 FDCAN 并启动 RX FIFO0 中断。
 *
 * @param hcan 已由 MX_FDCANx_Init() 初始化的 FDCAN 句柄，例如 &hfdcan3。
 *
 * @return true  过滤器配置、外设启动和中断使能全部成功。
 * @return false 句柄为空，或上述任一步骤返回 HAL_ERROR。
 *
 * @note 每个 FDCAN 句柄调用一次。调用前完成 MX_FDCANx_Init()。
 */
bool Can_Init(FDCAN_HandleTypeDef *hcan);

/**
 * @brief 发送一帧标准经典 CAN 数据帧。
 *
 * @param id   11 位标准 ID，范围 0x000～0x7FF。
 * @param data 数据缓冲区首地址。
 * @param size 数据长度，范围 0～8 字节。
 *
 * @return true  帧已写入 FDCAN 发送 FIFO。
 * @return false 句柄为空、参数超出范围，或发送 FIFO 写入返回 HAL_ERROR。
 *
 * @note 该函数完成入队后立即返回。总线发送由 FDCAN 外设完成。
 */
bool Can_Send(uint32_t id, const uint8_t *data, uint8_t size);

#ifdef __cplusplus
}
#endif

#endif /* CAN_H */
```



### 4\.3 `can.c`



```C
/**
 * @file can.c
 * @brief FDCAN 经典帧收发实现。
 *
 * 本文件负责：
 *   1. 过滤器配置与外设启动。
 *   2. 标准帧发送。
 *
 * 接收由应用层的 HAL_FDCAN_RxFifo0Callback() 完成。
 */

#include "can.h"

#include <stddef.h>

/* 当前 FDCAN 句柄。一个 Can 驱动实例对应一个 FDCAN 外设。 */
static FDCAN_HandleTypeDef *s_can;

bool Can_Init(FDCAN_HandleTypeDef *hcan)
{
    /* 过滤器配置结构，先全部清零。 */
    FDCAN_FilterTypeDef filter = {0};

    if (hcan == NULL)
    {
        return false;
    }

    s_can = hcan;

    /*
     * 过滤器 0：
     *   IdType       = 标准 ID
     *   FilterType   = 掩码模式
     *   FilterID1    = 0
     *   FilterID2    = 0
     *
     * 掩码为 0 时，全部标准 ID 都满足过滤条件。
     * FilterConfig 指定满足条件的帧进入 RX FIFO0。
     */
    filter.IdType = FDCAN_STANDARD_ID;
    filter.FilterIndex = 0U;
    filter.FilterType = FDCAN_FILTER_MASK;
    filter.FilterConfig = FDCAN_FILTER_TO_RXFIFO0;
    filter.FilterID1 = 0U;
    filter.FilterID2 = 0U;

    if (HAL_FDCAN_ConfigFilter(hcan, &filter) != HAL_OK)
    {
        return false;
    }

    /*
     * 全局过滤器：
     *   标准帧进入 RX FIFO0。
     *   扩展帧由硬件过滤。
     *   远程帧由硬件过滤。
     *
     * 过滤器 0 已经接收全部标准帧，此处的标准帧配置作为补充配置。
     */
    if (HAL_FDCAN_ConfigGlobalFilter(hcan,
                                     FDCAN_ACCEPT_IN_RX_FIFO0,
                                     FDCAN_REJECT,
                                     FDCAN_REJECT_REMOTE,
                                     FDCAN_REJECT_REMOTE) != HAL_OK)
    {
        return false;
    }

    /* 启动 FDCAN，进入正常收发状态。 */
    if (HAL_FDCAN_Start(hcan) != HAL_OK)
    {
        return false;
    }

    /*
     * 使能 RX FIFO0 新消息中断。
     * 应用层的 HAL_FDCAN_RxFifo0Callback() 由该中断触发。
     */
    if (HAL_FDCAN_ActivateNotification(hcan,
                                       FDCAN_IT_RX_FIFO0_NEW_MESSAGE,
                                       0U) != HAL_OK)
    {
        return false;
    }

    return true;
}

bool Can_Send(uint32_t id, const uint8_t *data, uint8_t size)
{
    /* 发送头结构，先全部清零。 */
    FDCAN_TxHeaderTypeDef header = {0};

    if ((s_can == NULL) || (data == NULL) || (size > 8U) || (id > 0x7FFU))
    {
        return false;
    }

    /*
     * 经典 CAN 帧头配置：
     *   Identifier          = 11 位标准 ID
     *   IdType              = 标准 ID
     *   TxFrameType         = 数据帧
     *   DataLength          = 数据长度；经典帧的 DLC 与字节数一致
     *   ErrorStateIndicator = FDCAN_ESI_ACTIVE（主动状态）
     *   BitRateSwitch       = 关闭比特率切换
     *   FDFormat            = 经典 CAN
     *   TxEventFifoControl  = 关闭发送事件
     *   MessageMarker       = 0
     */
    header.Identifier = id;
    header.IdType = FDCAN_STANDARD_ID;
    header.TxFrameType = FDCAN_DATA_FRAME;
    header.DataLength = size;
    header.ErrorStateIndicator = FDCAN_ESI_ACTIVE;
    header.BitRateSwitch = FDCAN_BRS_OFF;
    header.FDFormat = FDCAN_CLASSIC_CAN;
    header.TxEventFifoControl = FDCAN_NO_TX_EVENTS;
    header.MessageMarker = 0U;

    /* 写入发送 FIFO；队列满或外设返回 HAL_ERROR 时，函数返回 false。 */
    return HAL_FDCAN_AddMessageToTxFifoQ(s_can,
                                         &header,
                                         (uint8_t *)data) == HAL_OK;
}
```



### 4\.4 接收回调



应用层实现以下回调。回调内完成读帧和电机解析：



```C
/**
 * @brief FDCAN RX FIFO0 新消息回调。
 *
 * @param hfdcan    触发中断的 FDCAN 句柄。
 * @param RxFifo0ITs 中断标志位。
 *
 * 处理流程：
 *   1. 确认句柄为 hfdcan3。
 *   2. 循环读取 RX FIFO0，直到 FIFO 为空。
 *   3. 过滤扩展帧、远程帧和超长帧。
 *   4. 将标准帧交给 M3508 与 M2006 的 Update() 解析。
 */
void HAL_FDCAN_RxFifo0Callback(FDCAN_HandleTypeDef *hfdcan,
                               uint32_t RxFifo0ITs)
{
    (void)RxFifo0ITs;

    /* 本示例使用 FDCAN3；其他实例按实际句柄修改。 */
    if (hfdcan != &hfdcan3)
    {
        return;
    }

    /* 一次中断内取空 RX FIFO0。 */
    while (HAL_FDCAN_GetRxFifoFillLevel(hfdcan, FDCAN_RX_FIFO0) > 0U)
    {
        FDCAN_RxHeaderTypeDef header;
        uint8_t data[8];

        /* 读取一帧；读取结果为 HAL_ERROR 时结束本次回调。 */
        if (HAL_FDCAN_GetRxMessage(hfdcan,
                                   FDCAN_RX_FIFO0,
                                   &header,
                                   data) != HAL_OK)
        {
            return;
        }

        /*
         * 仅处理标准数据帧。
         * 经典帧的 DataLength 范围为 0～8。
         */
        if ((header.IdType != FDCAN_STANDARD_ID) ||
            (header.RxFrameType != FDCAN_DATA_FRAME) ||
            (header.DataLength > 8U))
        {
            continue;
        }

        /* 将帧交给两组电机对象；函数内部按 ID 范围筛选。 */
        Motor3508_Update(&g_m3508,
                         header.Identifier,
                         data,
                         (uint8_t)header.DataLength);
        Motor2006_Update(&g_m2006,
                         header.Identifier,
                         data,
                         (uint8_t)header.DataLength);
    }
}
```



### 4\.5 使用要点



- `Can_Init(&hfdcan3);` 在 `MX_FDCAN3_Init()` 之后调用，每个句柄调用一次。

- `HAL_FDCAN_RxFifo0Callback()` 由应用层实现；工程中已有该函数时，将上述读帧逻辑合并到现有实现。

- 回调内完成读帧和电机 `Update()`，函数体保持短小。

- `Can_Send()` 完成入队后返回，控制循环按控制周期调用电机 `Send()`。

- FDCAN3 的 RX FIFO0 深度为 8 帧，回调一次取空 FIFO。

- 一个 `Can` 实例管理一个 FDCAN 句柄；多路 CAN 场景按同一模式增加实例。

- 多帧连续到达时，回调按 FIFO 顺序逐帧解析。

## 5\. 电机公共数据结构



### 5\.1 `dji_motor.h`



```C
/**
 * @file dji_motor.h
 * @brief M3508 与 M2006 共用的电机组数据结构。
 *
 * 一个对象对应一个控制帧和四个槽位：
 *   槽位 0 -> 反馈 ID 基地址 + 0
 *   槽位 1 -> 反馈 ID 基地址 + 1
 *   槽位 2 -> 反馈 ID 基地址 + 2
 *   槽位 3 -> 反馈 ID 基地址 + 3
 *
 * 以 0x200 组为例：
 *   槽位 0 的反馈 ID 为 0x201
 *   槽位 1 的反馈 ID 为 0x202
 *   槽位 2 的反馈 ID 为 0x203
 *   槽位 3 的反馈 ID 为 0x204
 *
 * 以 0x1FF 组为例：
 *   槽位 0 的反馈 ID 为 0x205
 *   槽位 1 的反馈 ID 为 0x206
 *   槽位 2 的反馈 ID 为 0x207
 *   槽位 3 的反馈 ID 为 0x208
 */

#ifndef DJI_MOTOR_H
#define DJI_MOTOR_H

#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

typedef struct
{
    /**
     * 原始控制量，由 SetCurrent() 写入，由 Send() 打包发送。
     * 写入范围：
     *   M3508：-16384～+16384
     *   M2006：-10000～+10000
     */
    int16_t command[4];

    /**
     * 输出轴累计角度，单位 rad。
     * 由编码器值和累计圈数换算得到。
     */
    float position[4];

    /**
     * 输出轴角速度，单位 rad/s。
     * 由反馈帧中的转子转速换算得到。
     */
    float velocity[4];

    /**
     * 反馈电流，单位 A。
     * 由反馈帧中的原始电流值换算得到。
     */
    float current[4];

    /**
     * 方向位：
     *   bit0 对应槽位 0
     *   bit1 对应槽位 1
     *   bit2 对应槽位 2
     *   bit3 对应槽位 3
     *
     * 对应位为 1 时，该槽位的控制量和反馈量同时取反。
     */
    uint8_t reversed;

    /**
     * 内部使用：最近一帧编码器值，范围 0～8191。
     * 初值为 0xFFFF，首帧到达后写入实际编码器值。
     */
    uint16_t encoder[4];

    /**
     * 内部使用：编码器累计圈数。
     * 正转跨过 8191→0 时加一，反转跨过 0→8191 时减一。
     */
    int32_t round[4];
} DjiMotor;

#ifdef __cplusplus
}
#endif

#endif /* DJI_MOTOR_H */
```



### 5\.2 字段说明



|字段|单位|说明|
|---|---|---|
|`command[4]`|原始值|待发送电流，写入前由型号驱动完成限幅和方向处理|
|`position[4]`|rad|输出轴累计角度|
|`velocity[4]`|rad/s|输出轴角速度|
|`current[4]`|A|反馈电流|
|`reversed`|位掩码|bit0～bit3 对应四个槽位|
|`encoder[4]`|计数|内部编码器缓存，初值 0xFFFF|
|`round[4]`|圈|内部多圈计数|



一个对象管理四台电机。槽位号直接作为数组下标使用，范围 0～3。

## 6\. M3508 驱动



### 6\.1 通信协议



M3508 由 C620 电调驱动，使用标准 CAN 经典帧。



控制帧：



|项目|内容|
|---|---|
|ID|`0x200`|
|长度|8 字节|
|字节 0～1|槽位 0 电流，int16，大端|
|字节 2～3|槽位 1 电流，int16，大端|
|字节 4～5|槽位 2 电流，int16，大端|
|字节 6～7|槽位 3 电流，int16，大端|



反馈帧：



|项目|内容|
|---|---|
|ID|`0x201`～`0x204`|
|长度|8 字节|
|字节 0～1|编码器值，0～8191|
|字节 2～3|转子转速，rpm，int16，大端|
|字节 4～5|原始电流反馈，int16，大端|
|字节 6|温度，摄氏度|
|字节 7|保留|



### 6\.2 参数



|参数|数值|
|---|---|
|原始电流上限|±16384|
|额定电流|20 A|
|原始值到电流|`20.0f / 16384.0f` A/LSB|
|减速比|`3591.0f / 187.0f`|
|编码器分辨率|8192 计数/圈|



### 6\.3 `motor_3508.h`



```C
/**
 * @file motor_3508.h
 * @brief M3508 + C620 电流控制接口。
 *
 * 控制帧：0x200
 * 反馈帧：0x201～0x204
 *
 * 一个 Motor3508 对象管理四个槽位。
 * 槽位号范围 0～3，对应反馈 ID 0x201～0x204。
 */

#ifndef MOTOR_3508_H
#define MOTOR_3508_H

#include <stdbool.h>
#include <stdint.h>

#include "dji_motor.h"

#ifdef __cplusplus
extern "C" {
#endif

/* 控制帧 ID，对应槽位 0～3 的反馈 ID 为 0x201～0x204。 */
#define MOTOR3508_TX_ID 0x200U
#define MOTOR3508_RX_ID 0x201U

/* C620 原始电流范围。 */
#define MOTOR3508_CURRENT_MAX 16384

/* M3508 对象与公共电机结构使用同一组字段。 */
typedef DjiMotor Motor3508;

/**
 * @brief 初始化 M3508 对象。
 *
 * @param motor   电机对象。
 * @param reversed 方向位掩码，bit0～bit3 对应槽位 0～3。
 *                 对应位为 1 时，该槽位的控制量和反馈量取反。
 *
 * 初始化完成后：
 *   command、position、velocity、current 全部清零；
 *   encoder 写入初值 0xFFFF；
 *   round 清零。
 */

/**
 * @brief 设置指定槽位的原始电流。
 *
 * @param motor   电机对象。

 * @param current 原始电流，范围 -16384～+16384。
 *
 * 函数内部完成范围限制和方向处理，结果写入 command[slot]。
 */
void Motor3508_SetCurrent(Motor3508 *motor, uint8_t slot, int16_t current);

/**
 * @brief 解析一帧 M3508 反馈。
 *
 * @param motor 电机对象。
```

```C
/**
 * @file motor_3508.c
 * @brief M3508 + C620 电流控制实现。
 *
 * 换算关系：
 *   电流(A)   = 原始电流 × (20 / 16384) × 方向
 *   转速(rad/s) = 转子 rpm × (2π / 60) / 减速比 × 方向
 *   角度(rad) = ((圈数 × 8192) + 编码器) × (2π / 8192) / 减速比 × 方向
 */

#include "motor_3508.h"

#include "can.h"

#include <stddef.h>

/* C620 反馈电流换算系数：20 A 对应 16384。 */
#define MOTOR3508_CURRENT_TO_AMP (20.0f / 16384.0f)

/* M3508 减速比。 */
#define MOTOR3508_GEAR_RATIO (3591.0f / 187.0f)

/* 圆周常数。 */
#define MOTOR3508_TWO_PI 6.283185307179586f

/* 编码器一圈计数。 */
#define MOTOR3508_ENCODER_MAX 8192

/* 编码器半圈计数，用于跨圈判断。 */
#define MOTOR3508_ENCODER_HALF 4096

void Motor3508_Init(Motor3508 *motor, uint8_t reversed)
{
    if (motor == NULL)
    {
        return;
    }

    for (uint8_t slot = 0U; slot < 4U; ++slot)
    {
        /* 控制量与反馈量清零。 */
        motor->command[slot] = 0;
        motor->position[slot] = 0.0f;
        motor->velocity[slot] = 0.0f;
        motor->current[slot] = 0.0f;

        /* 编码器初值使用 0xFFFF，首帧到达后写入实际值。 */
        motor->encoder[slot] = 0xFFFFU;

        /* 多圈计数清零。 */
        motor->round[slot] = 0;
    }

    motor->reversed = reversed;
}

void Motor3508_SetCurrent(Motor3508 *motor, uint8_t slot, int16_t current)
{
    if ((motor == NULL) || (slot >= 4U))
    {
        return;
    }

    /* 限制到 C620 原始电流范围。 */
    if (current > MOTOR3508_CURRENT_MAX)
    {
        current = MOTOR3508_CURRENT_MAX;
    }
    else if (current < -MOTOR3508_CURRENT_MAX)
    {
        current = -MOTOR3508_CURRENT_MAX;
    }

    /* 对应槽位的方向位为 1 时，控制量取反。 */
    if ((motor->reversed & (1U << slot)) != 0U)
    {
        current = (int16_t)-current;
    }

    motor->command[slot] = current;
}

void Motor3508_Update(Motor3508 *motor,
                      uint32_t id,
                      const uint8_t *data,
                      uint8_t size)
{
    uint8_t slot;
    uint16_t encoder;
    int16_t speed_rpm;
    int16_t current_raw;
    int32_t difference;
    float direction;

    /* 反馈帧固定为 8 字节。 */
    if ((motor == NULL) || (data == NULL) || (size != 8U))
    {
        return;
    }

    /* 本对象处理 0x201～0x204。 */
    if ((id < MOTOR3508_RX_ID) || (id >= (MOTOR3508_RX_ID + 4U)))
    {
        return;
    }

    /* 反馈 ID 与槽位的对应关系：0x201 -> 0，0x204 -> 3。 */
    slot = (uint8_t)(id - MOTOR3508_RX_ID);

    /* 编码器按 16 位值读取，转速和电流按 int16 大端读取。 */
    encoder = (uint16_t)(((uint16_t)data[0] << 8U) | data[1]);
    speed_rpm = (int16_t)(((uint16_t)data[2] << 8U) | data[3]);
    current_raw = (int16_t)(((uint16_t)data[4] << 8U) | data[5]);

    /* data[6] 为温度，data[7] 为保留字节；本驱动使用编码器、转速和电流。 */

    /*
     * 多圈计数：
     *   编码器从接近 8191 的值跳到接近 0 的值时，判定为正转跨圈，
     *   round 加一；
     *   编码器从接近 0 的值跳到接近 8191 的值时，判定为反转跨圈，
     *   round 减一。
     *
     * 首帧到达时建立基准，round 保持为 0。
     */
    if (motor->encoder[slot] != 0xFFFFU)
    {
        difference = (int32_t)encoder - (int32_t)motor->encoder[slot];

        if (difference < -MOTOR3508_ENCODER_HALF)
        {
            motor->round[slot]++;
        }
        else if (difference > MOTOR3508_ENCODER_HALF)
        {
            motor->round[slot]--;
        }
    }
    else
    {
        motor->round[slot] = 0;
    }

    motor->encoder[slot] = encoder;

    /* 方向位为 1 时取反。 */
    direction = ((motor->reversed & (1U << slot)) != 0U) ? -1.0f : 1.0f;

    /*
     * 输出轴累计角度：
     *   (round × 8192 + encoder) × 2π / 8192 / 减速比。
     */
    motor->position[slot] = direction *
        ((float)motor->round[slot] * (float)MOTOR3508_ENCODER_MAX +
         (float)encoder) *
        (MOTOR3508_TWO_PI / (float)MOTOR3508_ENCODER_MAX) /
        MOTOR3508_GEAR_RATIO;

    /*
     * 输出轴角速度：
     *   转子 rpm × 2π / 60 / 减速比。
     */
    motor->velocity[slot] = direction *
        (float)speed_rpm * (MOTOR3508_TWO_PI / 60.0f) /
        MOTOR3508_GEAR_RATIO;

    /*
     * 反馈电流：
     *   原始电流 × 20 A / 16384。
     */
    motor->current[slot] =
        direction * (float)current_raw * MOTOR3508_CURRENT_TO_AMP;
}

bool Motor3508_Send(Motor3508 *motor)
{
    uint8_t data[8];

    if (motor == NULL)
    {
        return false;
    }

    /*
     * 按大端 int16 打包四个槽位的控制量：
     *   data[0..1] = 槽位 0
     *   data[2..3] = 槽位 1
     *   data[4..5] = 槽位 2
     *   data[6..7] = 槽位 3
     */
    for (uint8_t slot = 0U; slot < 4U; ++slot)
    {
        uint16_t value = (uint16_t)motor->command[slot];

        data[2U * slot] = (uint8_t)(value >> 8U);
        data[2U * slot + 1U] = (uint8_t)value;
    }

    return Can_Send(MOTOR3508_TX_ID, data, 8U);
}
```

### 6\.5 使用说明



- 在 `Can_Init()` 之前调用 `Motor3508_Init()`，使首帧反馈到达时编码器基准已经就绪。

- 在 `HAL_FDCAN_RxFifo0Callback()` 中调用 `Motor3508_Update()`，完成反馈解析。

- 在控制循环中调用 `Motor3508_SetCurrent()` 写入四个槽位的目标电流。

- 控制循环以 1 kHz 的频率调用 `Motor3508_Send()`，四个槽位共用一个 `0x200` 帧。

- 槽位号对应反馈 ID：槽位 0 对应 `0x201`，槽位 3 对应 `0x204`。

- `reversed` 的 bit0～bit3 分别控制四个槽位的方向。

- 链路长时间停止发送有效帧后，调用 `Motor3508_Init()` 重新建立位置基准。

## 8\. 蜂鸣器驱动



### 8\.1 硬件与行为



蜂鸣器连接 TIM12\_CH2（PB15）。TIM12 计数时钟为 1 MHz，比较值决定占空比。



- `Buzzer_Init()`：配置为 2 kHz、占空比 0，停止 PWM。

- `Buzzer_Tone(hz)`：配置频率并启动 PWM，占空比固定 50%。

- `Buzzer_Off()`：停止 PWM，比较值清零。

    

TIM12 为 16 位定时器，1 MHz 计数时 ARR 范围为 0～65535，对应频率下限约 15\.26 Hz。驱动将频率范围限制为 16 Hz～500 kHz。

```C
/**
 * @file buzzer.c
 * @brief TIM12_CH2（PB15）PWM 蜂鸣器实现。
 */

#include "buzzer.h"

#include "tim.h"

/* 计数时钟：240 MHz / 240 = 1 MHz。 */
#define BUZZER_TIMER_CLOCK 1000000UL

/* 频率范围。 */
#define BUZZER_MIN_HZ 16UL
#define BUZZER_MAX_HZ 500000UL

void Buzzer_Init(void)
{
    /* 预分频 240 - 1，得到 1 MHz 计数时钟。 */
    __HAL_TIM_SET_PRESCALER(&htim12, 240U - 1U);

    /* 默认频率 2 kHz，对应 ARR = 1 MHz / 2 kHz - 1。 */
    __HAL_TIM_SET_AUTORELOAD(&htim12, BUZZER_TIMER_CLOCK / 2000UL - 1U);

    /* 占空比 0，比较值为 0。 */
    __HAL_TIM_SET_COMPARE(&htim12, TIM_CHANNEL_2, 0U);

    /* 产生更新事件，使预分频和 ARR 立即生效。 */
    HAL_TIM_GenerateEvent(&htim12, TIM_EVENTSOURCE_UPDATE);

    /* 停止 PWM 输出。 */
    (void)HAL_TIM_PWM_Stop(&htim12, TIM_CHANNEL_2);
}

void Buzzer_Tone(uint32_t hz)
{
    uint32_t period;

    /* 频率范围检查。 */
    if ((hz < BUZZER_MIN_HZ) || (hz > BUZZER_MAX_HZ))
    {
        return;
    }

    /* 计算一个周期对应的计数值。 */
    period = BUZZER_TIMER_CLOCK / hz;

    /* 设置周期。 */
    __HAL_TIM_SET_AUTORELOAD(&htim12, period - 1U);

    /* 50% 占空比。 */
    __HAL_TIM_SET_COMPARE(&htim12, TIM_CHANNEL_2, period / 2U);

    /* 产生更新事件，使新的 ARR 和比较值立即生效。 */
    HAL_TIM_GenerateEvent(&htim12, TIM_EVENTSOURCE_UPDATE);

    /* 启动 PWM。 */
    (void)HAL_TIM_PWM_Start(&htim12, TIM_CHANNEL_2);
}

void Buzzer_Off(void)
{
    /* 停止 PWM。 */
    (void)HAL_TIM_PWM_Stop(&htim12, TIM_CHANNEL_2);

    /* 比较值清零，输出保持低电平。 */
    __HAL_TIM_SET_COMPARE(&htim12, TIM_CHANNEL_2, 0U);
}
```



### 8\.4 使用说明



```C

/* 2 kHz 提示音，持续 100 ms。 */

HAL_Delay(100U);
Buzzer_Off();
```



- 蜂鸣器为 PWM 驱动型，频率决定音调。

- 频率范围 16 Hz～500 kHz，常用提示音在 1 kHz～4 kHz。

- `Buzzer_Tone()` 会将占空比设为 50%。

## 9\. LED 驱动



### 9\.1 硬件与编码



板载 RGB LED 为 WS2812，数据线连接 SPI6\_MOSI（PA7），SPI6\_SCK（PA5）由 SPI 外设输出。



SPI6 配置：



- 主机模式

- 只发模式

- 8 bit 数据

- 6 Mbit/s

- CPOL = 0，CPHA = 2Edge

    

WS2812 位编码：



|逻辑位|SPI 字节|高电平时间|低电平时间|
|---|---|---|---|
|0|`0x60`|约 0\.33 μs|约 1\.00 μs|
|1|`0x78`|约 0\.67 μs|约 0\.67 μs|



一帧数据包含：



- 24 字节颜色数据，顺序为 G、R、B；

- 32 字节 0x00 复位。

    

总长度 56 字节，6 Mbit/s 下耗时约 75 μs。

### 9\.3 `led.c`



```C
/**
 * @file led.c
 * @brief SPI6 WS2812 RGB LED 实现。
 *
 * WS2812 位编码：
 *   逻辑 0 -> 0x60
 *   逻辑 1 -> 0x78
 *
 * 颜色顺序：G、R、B。
 */

#include "led.h"

#include "main.h"

/* 24 字节颜色 + 32 字节复位。 */
#define LED_BYTES 56U

/* 颜色数据长度。 */
#define LED_COLOR_BYTES 24U

/* 发送缓冲区。 */
static uint8_t s_tx[LED_BYTES];

/**
 * @brief 将一个字节编码为 8 个 SPI 字节。
 *
 * @param value 待编码字节。
 * @param out   输出缓冲区，长度 8 字节。
 */
static void led_encode(uint8_t value, uint8_t *out)
{
    for (uint8_t bit = 0U; bit < 8U; ++bit)
    {
        /* 从最高位开始，1 输出 0x78，0 输出 0x60。 */
        out[bit] = ((value & (0x80U >> bit)) != 0U) ? 0x78U : 0x60U;
    }
}

void Led_Init(void)
{
    /* 使能 SPI6。 */
    LL_SPI_Enable(SPI6);

    /* 发送黑色，确保上电后 LED 熄灭。 */
    Led_Off();
}

void Led_SetRGB(uint8_t red, uint8_t green, uint8_t blue)
{
    /* 按 GRB 顺序编码 24 字节颜色数据。 */
    led_encode(green, &s_tx[0]);
    led_encode(red, &s_tx[8]);
    led_encode(blue, &s_tx[16]);

    /* 颜色数据之后的 32 字节清零，作为复位信号。 */
    for (uint8_t i = LED_COLOR_BYTES; i < LED_BYTES; ++i)
    {
        s_tx[i] = 0U;
    }

    /* 清除上一次传输完成标志。 */
    LL_SPI_ClearFlag_EOT(SPI6);

    /* 设置传输长度并启动主机传输。 */
    LL_SPI_SetTransferSize(SPI6, LED_BYTES);
    LL_SPI_StartMasterTransfer(SPI6);

    /* 逐字节写入发送寄存器。 */
    for (uint8_t i = 0U; i < LED_BYTES; ++i)
    {
        while (LL_SPI_IsActiveFlag_TXP(SPI6) == 0U)
        {
        }

        LL_SPI_TransmitData8(SPI6, s_tx[i]);
    }

    /* 等待传输完成。 */
    while (LL_SPI_IsActiveFlag_EOT(SPI6) == 0U)
    {
    }

    /* 清除传输完成标志。 */
    LL_SPI_ClearFlag_EOT(SPI6);
}

void Led_Off(void)
{
    Led_SetRGB(0U, 0U, 0U);
}
```



### 9\.4 使用说明



```C
Led_Init();

/* 蓝色 */

/* 红色 */

/* 熄灭 */
Led_Off();
```



- `Led_SetRGB()` 为阻塞发送，函数返回时一帧数据已经写入 SPI。

- 颜色数据顺序为 GRB，接口参数顺序为 R、G、B。

- 32 字节复位对应约 42\.7 μs 低电平；实际 LED 需要更长复位时间时，将 `LED_BYTES` 和清零循环长度同步增加。

```C
/**
 * @file servo.c
 * @brief TIM1/TIM2 四路 50 Hz 舵机实现。
 */

#include "servo.h"

#include "tim.h"

/* 通道与定时器句柄的对应关系。 */
static TIM_HandleTypeDef *const s_timers[4] =
{
    &htim1,
    &htim1,
    &htim2,
    &htim2
};

/* 通道与定时器通道的对应关系。 */
static const uint32_t s_channels[4] =
{
    TIM_CHANNEL_1,
    TIM_CHANNEL_3,
    TIM_CHANNEL_1,
    TIM_CHANNEL_3
};

void Servo_Init(void)
{
    /* TIM1：1 MHz 计数，20 ms 周期。 */
    __HAL_TIM_SET_PRESCALER(&htim1, 240U - 1U);
    __HAL_TIM_SET_AUTORELOAD(&htim1, 20000U - 1U);
    __HAL_TIM_SET_COUNTER(&htim1, 0U);
    HAL_TIM_GenerateEvent(&htim1, TIM_EVENTSOURCE_UPDATE);

    /* TIM2：1 MHz 计数，20 ms 周期。 */
    __HAL_TIM_SET_PRESCALER(&htim2, 240U - 1U);
    __HAL_TIM_SET_AUTORELOAD(&htim2, 20000U - 1U);
    __HAL_TIM_SET_COUNTER(&htim2, 0U);
    HAL_TIM_GenerateEvent(&htim2, TIM_EVENTSOURCE_UPDATE);

    /* 四路默认脉宽 1500 μs，并停止输出。 */
    for (uint8_t channel = 0U; channel < 4U; ++channel)
    {
        __HAL_TIM_SET_COMPARE(s_timers[channel],
                              s_channels[channel],
                              1500U);
        (void)HAL_TIM_PWM_Stop(s_timers[channel], s_channels[channel]);
    }

    /* 初始化完成后关闭舵机电源。 */
    Servo_Power(false);
}

void Servo_Set(uint8_t channel, uint16_t pulse_us)
{
    /* 通道号范围和脉宽范围检查。 */
    if ((channel >= 4U) || (pulse_us > 20000U))
    {
        return;
    }

    __HAL_TIM_SET_COMPARE(s_timers[channel], s_channels[channel], pulse_us);
}

void Servo_On(uint8_t channel)
{
    if (channel >= 4U)
    {
        return;
    }

    (void)HAL_TIM_PWM_Start(s_timers[channel], s_channels[channel]);
}

void Servo_Off(uint8_t channel)
{
    if (channel >= 4U)
    {
        return;
    }

    (void)HAL_TIM_PWM_Stop(s_timers[channel], s_channels[channel]);
}

void Servo_Power(bool enable)
{
    HAL_GPIO_WritePin(POWER_PWM_GPIO_Port,
                      POWER_PWM_Pin,
                      enable ? GPIO_PIN_SET : GPIO_PIN_RESET);
}
```

## 11\. FXI6X 驱动



### 11\.1 协议



FXI6X 接收机配置为 SBUS 输出，连接 UART5：



- 100000 baud

- 9 bit 字长

- 偶校验

- 1 停止位

    

每帧 25 字节：



|字节|内容|
|---|---|
|0|帧头 `0x0F`|
|1～22|16 个 11 bit 通道，低位在前|
|23|标志位：bit2 = frame lost，bit3 = failsafe|
|24|帧尾 `0x00`|



驱动解析前 10 个通道：



|字段|通道|说明|
|---|---|---|
|`rocker_r_h`|CH1|右摇杆水平|
|`rocker_r_v`|CH2|右摇杆垂直|
|`rocker_l_v`|CH3|左摇杆垂直|
|`rocker_l_h`|CH4|左摇杆水平|
|`knob_l`|CH5|左旋钮|
|`knob_r`|CH6|右旋钮|
|`switch_a`|CH7|开关 A|
|`switch_b`|CH8|开关 B|
|`switch_c`|CH9|开关 C|
|`switch_d`|CH10|开关 D|



归一化规则：



- 原始通道值为 11 bit 减去 1024，范围 \-1024～1023。

- 模拟通道有效范围 \-784～783。

- 模拟量按 783 或 784 归一化到 \-1\.0～1\.0。

- 开关阈值 ±392：小于 \-392 为 HIGH，大于 392 为 LOW，其余为 MIDDLE。

```C
 *
```

### 11\.3 `fxi6x.c`



```C
/**
 * @file fxi6x.c
 * @brief FXI6X SBUS 遥控接收实现。
 *
 * 接收路径：
 *   1. UART5 接收中断把字节写入环形缓冲区。
 *   2. Fxi6x_Update() 在主循环中按 25 字节组帧。
 *   3. 帧头和帧尾匹配后解析 10 个通道。
 */

#include "fxi6x.h"

#include "usart.h"

#include <string.h>

/* SBUS 帧长度。 */
#define FXI6X_FRAME_SIZE 25U

/* 环形缓冲区大小，可缓存约 12.8 ms 的 100 kbaud 数据。 */
#define FXI6X_RING_SIZE 128U

/* 通道中值。 */
#define FXI6X_CENTER 1024

/* 模拟通道有效范围。 */
#define FXI6X_MIN (-784)
#define FXI6X_MAX 783

/* 开关阈值。 */
#define FXI6X_SWITCH_THRESHOLD 392

/* UART5 单字节接收缓存。 */
static uint8_t s_byte;

/* 环形缓冲区读写位置。 */
static volatile uint16_t s_head;
static volatile uint16_t s_tail;
static uint8_t s_ring[FXI6X_RING_SIZE];

/* 组帧缓存和当前长度。 */
static uint8_t s_frame[FXI6X_FRAME_SIZE];
static uint8_t s_len;

/* 最近一帧遥控数据。 */
static Fxi6x_Data s_data;

/**
 * @brief 从环形缓冲区取出一个字节。
 *
 * @param byte 输出字节。
 *
 * @return true  取到字节。
 * @return false 缓冲区为空。
 */
static bool fxi6x_pop(uint8_t *byte)
{
    if (s_tail == s_head)
    {
        return false;
    }

    *byte = s_ring[s_tail];
    s_tail = (uint16_t)((s_tail + 1U) % FXI6X_RING_SIZE);
    return true;
}

/**
 * @brief 从两个字节中提取一个 11 bit 通道。
 *
 * @param high  高字节。
 * @param low   低字节。
 * @param shift 右移位数。
 *
 * @return 减去中值后的通道值，范围 -1024～1023。
 */
static int16_t fxi6x_channel(uint8_t high, uint8_t low, uint8_t shift)
{
    uint16_t raw = (uint16_t)(((uint16_t)high << 8U) | low);

    return (int16_t)((int32_t)((raw >> shift) & 0x07FFU) - FXI6X_CENTER);
}

/**
 * @brief 将模拟通道值归一化到 -1.0～1.0。
 *
 * @param value 通道值，范围 -784～783。
 *
 * @return 归一化结果。
 */
static float fxi6x_normalize(int16_t value)
{
    if (value >= 0)
    {
        float result = (float)value / (float)FXI6X_MAX;

        return (result > 1.0f) ? 1.0f : result;
    }

    {
        float result = (float)value / (float)(-FXI6X_MIN);

        return (result < -1.0f) ? -1.0f : result;
    }
}

/**
 * @brief 将开关通道值映射为 HIGH、MIDDLE、LOW。
 *
 * @param value 通道值。
 *
 * @return 开关状态。
 */
static uint8_t fxi6x_switch(int16_t value)
{
    if (value < -FXI6X_SWITCH_THRESHOLD)
    {
        return FXI6X_HIGH;
    }

    if (value > FXI6X_SWITCH_THRESHOLD)
    {
        return FXI6X_LOW;
    }

    return FXI6X_MIDDLE;
}

/**
 * @brief 校验模拟通道值落在有效范围。
 *
 * @param value 通道值。
 *
 * @return true 表示值在 -784～783 以内。
 */
static bool fxi6x_valid(int16_t value)
{
    return (value >= FXI6X_MIN) && (value <= FXI6X_MAX);
}

/**
 * @brief 将摇杆、旋钮和开关恢复到中位。
 */
static void fxi6x_clear(void)
{
    s_data.rocker_l_h = 0.0f;
    s_data.rocker_l_v = 0.0f;
    s_data.rocker_r_h = 0.0f;
    s_data.rocker_r_v = 0.0f;

    s_data.knob_l = 0.0f;
    s_data.knob_r = 0.0f;

    s_data.switch_a = FXI6X_HIGH;
    s_data.switch_b = FXI6X_HIGH;
    s_data.switch_c = FXI6X_HIGH;
    s_data.switch_d = FXI6X_HIGH;
}

/**
 * @brief 解析一帧 25 字节 SBUS 数据。
 *
 * @param frame 帧缓冲区。
 *
 * @return true  帧有效且处于正常工作状态。
 * @return false 帧为 failsafe 状态，或模拟通道超出有效范围。
 */
static bool fxi6x_decode(const uint8_t *frame)
{
    int16_t channel[10];

    /* 按 11 bit 小端格式提取前 10 个通道。 */
    channel[0] = fxi6x_channel(frame[2], frame[1], 0U);
    channel[1] = fxi6x_channel(frame[3], frame[2], 3U);

    channel[2] = (int16_t)((int32_t)(
        (((uint32_t)frame[5] << 10U) |
         ((uint32_t)frame[4] << 2U) |
         ((uint32_t)frame[3] >> 6U)) & 0x07FFU) - FXI6X_CENTER);

    channel[3] = fxi6x_channel(frame[6], frame[5], 1U);
    channel[4] = fxi6x_channel(frame[7], frame[6], 4U);

    channel[5] = (int16_t)((int32_t)(
        (((uint32_t)frame[9] << 9U) |
         ((uint32_t)frame[8] << 1U) |
         ((uint32_t)frame[7] >> 7U)) & 0x07FFU) - FXI6X_CENTER);

    channel[6] = fxi6x_channel(frame[10], frame[9], 2U);
    channel[7] = fxi6x_channel(frame[11], frame[10], 5U);
    channel[8] = fxi6x_channel(frame[13], frame[12], 0U);
    channel[9] = fxi6x_channel(frame[14], frame[13], 3U);

    /* 读取接收机标志位。 */
    s_data.frame_lost = (frame[23] & 0x04U) != 0U;
    s_data.failsafe = (frame[23] & 0x08U) != 0U;

    /* 写入归一化后的摇杆和旋钮值。 */
    s_data.rocker_r_h = fxi6x_normalize(channel[0]);
    s_data.rocker_r_v = fxi6x_normalize(channel[1]);
    s_data.rocker_l_v = fxi6x_normalize(channel[2]);
    s_data.rocker_l_h = fxi6x_normalize(channel[3]);
    s_data.knob_l = fxi6x_normalize(channel[4]);
    s_data.knob_r = fxi6x_normalize(channel[5]);

    /* 写入开关状态。 */
    s_data.switch_a = fxi6x_switch(channel[6]);
    s_data.switch_b = fxi6x_switch(channel[7]);
    s_data.switch_c = fxi6x_switch(channel[8]);
    s_data.switch_d = fxi6x_switch(channel[9]);

    /*
     * failsafe 帧或模拟通道超出范围时，
     * 将摇杆、旋钮和开关恢复到中位，并返回 false。
     */
    if (s_data.failsafe ||
        (!fxi6x_valid(channel[0])) ||
        (!fxi6x_valid(channel[1])) ||
        (!fxi6x_valid(channel[2])) ||
        (!fxi6x_valid(channel[3])) ||
        (!fxi6x_valid(channel[4])) ||
        (!fxi6x_valid(channel[5])))
    {
        fxi6x_clear();
        return false;
    }

    return true;
}

bool Fxi6x_Init(void)
{
    /* 清空环形缓冲区和组帧状态。 */
    s_head = 0U;
    s_tail = 0U;
    s_len = 0U;

    /* 清空数据，并将开关置于 HIGH。 */
    memset(&s_data, 0, sizeof(s_data));
    s_data.switch_a = FXI6X_HIGH;
    s_data.switch_b = FXI6X_HIGH;
    s_data.switch_c = FXI6X_HIGH;
    s_data.switch_d = FXI6X_HIGH;

    /* 启动 UART5 单字节中断接收。 */
    return HAL_UART_Receive_IT(&huart5, &s_byte, 1U) == HAL_OK;
}

bool Fxi6x_Update(void)
{
    bool got = false;
    uint8_t byte;

    /* 逐字节组帧。 */
    while (fxi6x_pop(&byte))
    {
        /* 帧首字节为 0x0F；组帧开始前跳过其他字节。 */
        if ((s_len == 0U) && (byte != 0x0FU))
        {
            continue;
        }

        s_frame[s_len] = byte;
        s_len++;

        /* 收集满 25 字节后检查帧头和帧尾。 */
        if (s_len == FXI6X_FRAME_SIZE)
        {
            if ((s_frame[0] == 0x0FU) && (s_frame[24] == 0x00U))
            {
                if (fxi6x_decode(s_frame))
                {
                    got = true;
                }
            }

            /* 每帧处理结束后，从下一个字节重新组帧。 */
            s_len = 0U;
        }
    }

    return got;
}

const Fxi6x_Data *Fxi6x_GetData(void)
{
    return &s_data;
}

/**
 * @brief UART5 接收完成回调。
 *
 * 将收到的字节写入环形缓冲区，并重新挂起单字节接收。
 *
 * @param huart 触发回调的 UART 句柄。
 */
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart->Instance != UART5)
    {
        return;
    }

    uint16_t next = (uint16_t)((s_head + 1U) % FXI6X_RING_SIZE);

    /* 缓冲区有空间时写入字节；空间占满时保留原有数据。 */
    if (next != s_tail)
    {
        s_ring[s_head] = s_byte;
        s_head = next;
    }

    /* 重新挂起单字节接收。 */
    (void)HAL_UART_Receive_IT(&huart5, &s_byte, 1U);
}
```



### 11\.4 使用说明



```C
Fxi6x_Init();

while (1)
{
    if (Fxi6x_Update())
    {
        const Fxi6x_Data *rc = Fxi6x_GetData();

        if (rc->failsafe)
        {
            /* 接收机处于 failsafe 状态。 */
        }
        else
        {
            /* 使用 rc->rocker_l_v、rc->knob_r 等字段。 */
        }
    }
}
```



- `Fxi6x_Init()` 在 `MX_UART5_Init()` 之后调用。

- `Fxi6x_Update()` 在主循环中调用，每次处理环形缓冲区中的全部字节。

- `failsafe` 为 true 时，摇杆、旋钮和开关已经恢复到中位。

- 链路超时由应用层处理：可以用 `HAL_GetTick()` 记录最近一次有效帧时间，也可以用循环计数。

- `HAL_UART_RxCpltCallback()` 由本驱动定义；工程中已有同名回调时，将 UART5 分支合并到现有实现。

- UART 恢复由应用层完成：检测到 overrun 后重新调用 `Fxi6x_Init()`，或清除标志并重新挂起接收。

## 12\. 集成示例



以下示例将 M3508 放在 `0x200` 组，将 M2006 放在 `0x1FF` 组。



```C
#include "can.h"
#include "motor_3508.h"
#include "motor_2006.h"
#include "buzzer.h"
#include "led.h"
#include "servo.h"
#include "fxi6x.h"

/* 两组电机对象。 */
static Motor3508 g_m3508;
static Motor2006 g_m2006;

/**
 * @brief FDCAN RX FIFO0 新消息回调。
 *
 * 读取全部待处理帧，并交给两组电机对象解析。
 */
void HAL_FDCAN_RxFifo0Callback(FDCAN_HandleTypeDef *hfdcan,
                               uint32_t RxFifo0ITs)
{
    (void)RxFifo0ITs;

    if (hfdcan != &hfdcan3)
    {
        return;
    }

    while (HAL_FDCAN_GetRxFifoFillLevel(hfdcan, FDCAN_RX_FIFO0) > 0U)
    {
        FDCAN_RxHeaderTypeDef header;
        uint8_t data[8];

        if (HAL_FDCAN_GetRxMessage(hfdcan,
                                   FDCAN_RX_FIFO0,
                                   &header,
                                   data) != HAL_OK)
        {
            return;
        }

        if ((header.IdType != FDCAN_STANDARD_ID) ||
            (header.RxFrameType != FDCAN_DATA_FRAME) ||
            (header.DataLength > 8U))
        {
            continue;
        }

        Motor3508_Update(&g_m3508,
                         header.Identifier,
                         data,
                         (uint8_t)header.DataLength);
        Motor2006_Update(&g_m2006,
                         header.Identifier,
                         data,
                         (uint8_t)header.DataLength);
    }
}

void app_init(void)
{
    /*
     * 先初始化电机对象，再启动 CAN 中断。
     * 首帧反馈到达时，编码器基准已经就绪。
     */
    Motor3508_Init(&g_m3508, 0x00U);
    Motor2006_Init(&g_m2006, 0x00U);

    Can_Init(&hfdcan3);

    Buzzer_Init();
    Led_Init();
    Servo_Init();
    Fxi6x_Init();

    /* 上电提示：2 kHz，100 ms。 */
    Buzzer_Tone(2000U);
    HAL_Delay(100U);
    Buzzer_Off();

    /* 舵机上电，通道 0 回中。 */
    Servo_Power(true);
    Servo_Set(0U, 1500U);
    Servo_On(0U);
}

void app_loop(void)
{
    const Fxi6x_Data *rc;

    /*
     * 记录距离最近一次有效遥控帧的循环次数。
     * 控制循环为 1 kHz 时，200 次约等于 200 ms。
     */
    static uint16_t rc_age;

    /* 解析遥控数据。 */
    if (Fxi6x_Update())
    {
        rc_age = 0U;
    }
    else if (rc_age < 1000U)
    {
        rc_age++;
    }

    rc = Fxi6x_GetData();

    /* 遥控链路超时或接收机 failsafe 时，电机电流清零。 */
    if ((rc_age > 200U) || rc->failsafe)
    {
        for (uint8_t slot = 0U; slot < 4U; ++slot)
        {
            Motor3508_SetCurrent(&g_m3508, slot, 0);
        }

        Motor2006_SetCurrent(&g_m2006, 0U, 0);
        Led_SetRGB(32U, 0U, 0U);
    }
    else
    {
        int16_t drive = (int16_t)(rc->rocker_l_v * 8000.0f);

        for (uint8_t slot = 0U; slot < 4U; ++slot)
        {
            Motor3508_SetCurrent(&g_m3508, slot, drive);
        }

        Motor2006_SetCurrent(&g_m2006,
                             0U,
                             (int16_t)(rc->knob_r * 5000.0f));
        Led_SetRGB(0U, 32U, 0U);
    }

    /* 每个控制周期发送两组电机控制帧。 */
    Motor3508_Send(&g_m3508);
    Motor2006_Send(&g_m2006);
}
```



初始化顺序：



1. `MX_FDCAN3_Init()`、`MX_TIMx_Init()`、`MX_SPI6_Init()`、`MX_UART5_Init()`。

2. `Motor3508_Init()`、`Motor2006_Init()`。

3. `Can_Init()`。

4. `Buzzer_Init()`、`Led_Init()`、`Servo_Init()`、`Fxi6x_Init()`。

    

控制流程：



1. CAN 中断触发 `HAL_FDCAN_RxFifo0Callback()`，更新电机反馈。

2. 主循环调用 `Fxi6x_Update()`，读取遥控数据。

3. 主循环调用 `Motor*_SetCurrent()`，写入目标电流。

4. 主循环调用 `Motor*_Send()`，发送控制帧。

5. 主循环更新 LED 状态。

### 13\.2 硬件核对



- FDCAN3 的 RX 为 PD12，TX 为 PD13，通信速率 1 Mbps。

- FDCAN3 的 RX FIFO0 与 TX FIFO 各 8 个元素。

- FDCAN3\_IT0/IT1 中断已使能。

- TIM12\_CH2 对应 PB15，计数时钟 1 MHz。

- TIM1\_CH1/CH3 对应 PE9/PE13，TIM2\_CH1/CH3 对应 PA0/PA2。

- SPI6\_SCK 对应 PA5，SPI6\_MOSI 对应 PA7。

- UART5\_RX 对应 PD2，UART5\_TX 对应 PC12。

- PC15 为舵机电源控制，输出高电平使能。

    

### 13\.3 运行检查



1. CAN 总线连接正常后，`HAL_FDCAN_RxFifo0Callback()` 以 1 kHz 的频率收到电机反馈。

2. `Motor3508_Update()` 和 `Motor2006_Update()` 按反馈 ID 更新对应槽位。

3. 控制循环以 1 kHz 的频率调用 `Motor*_Send()`，两组电机分别收到 `0x200` 和 `0x1FF` 控制帧。

4. 蜂鸣器调用 `Buzzer_Tone(2000U)` 后发出 2 kHz 提示音。

5. LED 依次设置红、绿、蓝，颜色顺序与 GRB 编码一致。

6. 舵机使能电源后，`Servo_Set(0U, 1500U)` 输出中位脉宽。

7. 遥控器摇杆动作时，`Fxi6x_GetData()` 中对应通道数值随之变化。

8. 遥控器停止发送后，`failsafe` 置位，应用层将电机电流清零。

    

### 13\.4 接口约定



- 一个 `Can` 实例对应一个 FDCAN 句柄。

- 一个电机对象对应一个控制帧和四个槽位。

- 电机对象在 `Can_Init()` 之前完成初始化。

- `HAL_FDCAN_RxFifo0Callback()` 由应用层实现；工程中已有该函数时，将读帧逻辑合并到现有实现。

- `HAL_UART_RxCpltCallback()` 由 `fxi6x.c` 定义；工程中已有该函数时，将 UART5 分支合并到现有实现。

- FXI6X 的链路超时由应用层根据 `Fxi6x_Update()` 的返回值或 `HAL_GetTick()` 处理。

- 电机对象由调用方静态定义；驱动内部对象使用静态存储。

- 代码按 STM32H7 HAL 接口编写，接入工程后按实际 HAL 版本完成编译验证。
